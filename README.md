# 🌊 SubGuessr

SubGuessr is a **Subnautica-inspired GeoGuessr game** where players try to guess their location on the Subnautica map based on a screenshot.

Test your map knowledge and see how close you can get!

---

## 🎮 How It Works

1. You are shown a random in-game screenshot.
2. You click on the map where you think the location is.
3. The game calculates the distance between your guess and the real location.
4. You get a score based on how accurate your guess was.
5. Repeat for multiple rounds!

## 📏 Scoring System

Score is calculated based on the distance between:
- Player guess
- Actual location

The closer the guess, the higher the score.
